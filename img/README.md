# Nunes Carvalho Advocacia

Site institucional desenvolvido para a Nunes Carvalho Advocacia como projeto da disciplina de Programação Web I.

## Sobre o projeto

O projeto consiste no desenvolvimento de um site institucional responsivo para apresentar a Nunes Carvalho Advocacia, suas áreas de atuação, profissionais e informações de contato.

O site foi desenvolvido utilizando HTML5, CSS3, Bootstrap e JavaScript.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5.3.3
- JavaScript
- Git
- GitHub
- GitHub Pages
